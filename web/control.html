OBS setup

  1. Sources → + → Browser, paste the URL, set Width 1280, Height 720 (or 1920×1080, since it scales).
  2. Put it above your camera source and stretch it to the canvas.
  3. Optional: Docks → Custom Browser Docks, add to switch layouts from inside OBS.
  4. A layout pinned in the URL ignores this panel, e.g. /?layout=hud, &scale=1.2, &accent=ff8800.
